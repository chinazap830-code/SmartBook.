# SmartBook.

A free, local-first study practice PWA.

## Use
1. Open the published Pages link.
2. Add a selectable-text TXT or Markdown textbook extract, or paste notes.
3. Save it on the device, then generate objective or fill-in-the-blank practice.
4. Mark answers to see the correct answer and source sentence.

## Offline
The app shell is cached by its service worker after the first successful online visit. Saved study material is stored in browser local storage on that device.

## Current limitations
- TXT and Markdown only; scanned PDFs, images and Word documents are not supported in this first published build.
- Question generation is a lightweight local sentence/keyword method, not an AI model. Check generated questions and source evidence.
- Data remains in the browser on the device; clearing browser storage can remove it.
